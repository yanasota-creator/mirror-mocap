# Mirror Mocap

PC内蔵カメラ1台で、体・顔（表情）・指の動きを推定して3Dアバターを動かすWebページです。
推定はすべてブラウザ内で行います（Google MediaPipe）。カメラ映像が外部に送られることはありません。

**すぐ使う**：https://yanasota-creator.github.io/mirror-mocap/ を Chrome / Edge / スマホのブラウザで開くだけです。

| フォルダ・ファイル | 中身 |
|---|---|
| `index.html` | Web版（本体） |
| `native/` | PC版の試作（Python トラッカー ＋ Unity）。使い方は `native/README.md` |
| `HANDOFF.md` | 開発の引き継ぎ資料 |

## 開き方（ファイルを手元で開く場合）

### いちばん簡単な方法
1. `index.html` をダウンロードする
2. **Chrome か Edge** にドラッグ＆ドロップして開く
3. 「カメラを開始」を押し、カメラの許可を求められたら「許可」を選ぶ

インターネット接続が必要です（初回にAIモデル約20MBと3D描画ライブラリを読み込むため）。

### カメラが使えないと言われたとき（ローカルサーバーで開く）
ブラウザは「安全な場所」のページにしかカメラを許可しません。Safari などではファイルを直接開くと拒否されることがあります。
その場合は、`index.html` があるフォルダでターミナルを開き、PCの中に小さなWebサーバーを立てます（Pythonが入っていれば使えます）。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終わったらターミナルで Ctrl+C を押すと止まります。

## できること
| 分類 | 機能 |
|---|---|
| 動き | 体・顔（表情・視線・口の形 あいうえお）・指の推定、正面リセット、ミラー、脚、体の位置（左右の移動・しゃがみ）、座りポーズ（脚が映っていないとき椅子に座る、机も置ける） |
| 表情 | 表情ボタン（喜怒哀驚穏、キーボードの 1〜5）、モデル独自の表情ボタン、指差しでレーザーポインター、ピース✌で笑顔、マイク口パク、自動まばたき・カメラ目線（マウスの方も見る）、待機中のゆらゆら、クリックで反応（頭を撫でると喜ぶ）、エフェクト（ハート・！・怒りマーク・涙） |
| 配信 | 背景（グリーンバック・ブルーバック・白・黒・好きな画像や動画）、照明（スタジオ・明るい・夕焼け・ネオン・夜）、天気（桜・雪・キラキラ・ハート）、カメラの追従、配信モード（F キー、Esc で戻る）、デスクトップに浮かべる小窓（ほかのアプリの上に常に表示）、カメラの自動移動、カメラ映像の非表示とロック（顔バレ防止） |
| モデル | 配布モデル13体、自分のVRM（読み込んだものはこのブラウザに保存され、次から一覧に出る） |
| 小物 | ボール・箱・マイク・ペンライト・ハート・魔法の杖（振るとキラキラ）・星を出して、手を握って掴む／開いて離す、もう片方の手に持ち替える。マウスや指でドラッグしても動かせる。重力オンで投げられる。頭や体に当たると跳ね返る。リフティングゲーム（頭や手で何回打ち上げられるか）、紙吹雪（ボタン、または拍手） |
| アクセサリー | ねこ耳・王冠・メガネ・天使の輪（頭の形を測って位置を合わせる） |
| 保存 | 録画（MP4 / WebM、声も入れられる、3秒カウントダウン）、ポーズ固定（Space キー）、スクリーンショット（PNG、P キー、背景を透明にもできる）、設定のファイル保存・読込、モーション記録（VRMA・BVH）、モーション再生（VRMA・BVH。配布されているダンスなどのVRMAも再生可） |
| 吹き出し | 入力した文字や、音声認識（オンにしたときだけ。音声は Google の音声認識に送られます）で文字にした言葉を、頭の横の吹き出しと VRChat のチャットボックスに出す |
| 外部連携 | PCで `native/bridge/bridge.py` を動かすと、VSeeFace・Warudo など（VMC）と VRChat（OSC トラッカー、チャットボックス、表情パラメータ、両手を上げてジャンプ）に送れる。逆に mocopi・iPhone の顔トラッキングアプリなどの VMC を受け取って動かすこともできる。使い方は `native/README.md` |

## 使い方のコツ
- 画面から60〜100cm離れて、ひじまで映ると腕が動きます
- 顔に正面から光が当たると、指と表情が安定します
- 姿勢が傾いて見えるときは、まっすぐ座って「正面リセット」を押します
- 配信や画面共有をするときは、「カメラ映像を表示」をオフにして「表示をロック」をオンにすると、うっかり顔が映るのを防げます（ロックを外すには確認が出ます。設定はブラウザに記憶されます）
- 自分のアバターを使うときは VRoid Studio などで書き出した `.vrm` ファイルを読み込みます

## しくみ（ざっくり）
| 部分 | 使っているもの |
|---|---|
| 体の33点 | MediaPipe Pose Landmarker |
| 顔の478点＋表情52種 | MediaPipe Face Landmarker |
| 手の21点×2 | MediaPipe Hand Landmarker |
| 3D表示 | three.js ＋ three-vrm |

推定した点の位置から「骨がどちらを向いているか」を計算し、アバターの関節の回転に変換しています。
ブレは One Euro フィルター（速い動きには素早く追従し、静止時のブレだけを消すフィルター）で抑えています。
