# Mirror Mocap

PC内蔵カメラ1台で、体・顔（表情）・指の動きを推定して3Dアバターを動かすWebページです。
推定はすべてブラウザ内で行います（Google MediaPipe）。カメラ映像が外部に送られることはありません。

**すぐ使う**：https://yanasota-creator.github.io/mirror-mocap/ を Chrome / Edge / スマホのブラウザで開くだけです。

| フォルダ・ファイル | 中身 |
|---|---|
| `index.html` | Web版（本体） |
| `native/` | PC版の試作（Python トラッカー ＋ Unity）。使い方は `native/README.md` |
| `HANDOFF.md` | 開発の引き継ぎ資料 |

## 開き方（ファイルを手元で開く場合）

### いちばん簡単な方法
1. `index.html` をダウンロードする
2. **Chrome か Edge** にドラッグ＆ドロップして開く
3. 「カメラを開始」を押し、カメラの許可を求められたら「許可」を選ぶ

インターネット接続が必要です（初回にAIモデル約20MBと3D描画ライブラリを読み込むため）。

### カメラが使えないと言われたとき（ローカルサーバーで開く）
ブラウザは「安全な場所」のページにしかカメラを許可しません。Safari などではファイルを直接開くと拒否されることがあります。
その場合は、`index.html` があるフォルダでターミナルを開き、PCの中に小さなWebサーバーを立てます（Pythonが入っていれば使えます）。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。終わったらターミナルで Ctrl+C を押すと止まります。

## 使い方のコツ
- 画面から60〜100cm離れて、ひじまで映ると腕が動きます
- 顔に正面から光が当たると、指と表情が安定します
- 姿勢が傾いて見えるときは、まっすぐ座って「正面リセット」を押します
- 自分のアバターを使うときは VRoid Studio などで書き出した `.vrm` ファイルを読み込みます

## しくみ（ざっくり）
| 部分 | 使っているもの |
|---|---|
| 体の33点 | MediaPipe Pose Landmarker |
| 顔の478点＋表情52種 | MediaPipe Face Landmarker |
| 手の21点×2 | MediaPipe Hand Landmarker |
| 3D表示 | three.js ＋ three-vrm |

推定した点の位置から「骨がどちらを向いているか」を計算し、アバターの関節の回転に変換しています。
ブレは One Euro フィルター（速い動きには素早く追従し、静止時のブレだけを消すフィルター）で抑えています。
